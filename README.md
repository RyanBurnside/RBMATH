This is a personal library to provide some math routines for generative stuff.

WIP - Need to write unit tests ...


The forms with ! in the name mutate the first vector in the parameters.

Otherwise functions are non-mutating. 
Except for V3F.SETXYZ, V3F.SETX, V3F.SETY, V3F.SETZ which do mutate.
